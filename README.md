# dsh-prompt-inject

给 **DeepSeek Harness** 用的系统提示词注入插件：在设置页里写一段话，它会作为**全局**系统提示词出现，当前会话、子代理、工作流派生的 agent 都会带上。

## 安装

DSH 里打开 **设置 → 插件 → 安装**，填：

```
github:chiina66/dsh-prompt-inject#v1.1.0
```

装完重启 DeepSeek Harness，设置左侧会多出「提示词注入」。

## 使用

打开 **设置 → 提示词注入**，写下你想要的规则，点保存——**下一个回合就生效**，不用重启。

```
比如：
- 回复先给结论，再给理由，尽量简短
- 代码注释用中文
- 不确定的事直接说不确定，不要猜
```

| 按钮 | 作用 |
|---|---|
| 保存修改 | 写入并立即生效 |
| 停用注入 / 启用注入 | 临时关掉，内容留着 |
| 清空 | 清掉正文 |
| 重新读取 | 按当前配置重置输入框 |

## 功能

- **全局生效**：不止当前会话，子代理和工作流里的 agent 都会拿到同一段提示词
- **位置可调**：默认排在系统提示词最下面（`order: 10300`），工具说明、人格后缀之后
- **热生效**：改完下一回合就变，不重启、不刷新
- **文件模式**：把 `contentFile` 指到一个 `.md`，改文件即生效，适合在编辑器里写长提示词
- **模型可改**：附带 `prompt_inject` 工具，可以直接对 agent 说「把注入改成 …」「关掉注入」
- **容错**：文件读不到、配置写不进去都只记日志降级，不影响 Harness 启动

## 配置

```yaml
- id: prompt-inject
  name: dsh-prompt-inject
  config:
    enabled: true       # 开关
    content: ''         # 正文，设置页编辑的就是它
    contentFile: ''     # 可选：改读文件，文件存在时优先于 content
    order: 10300        # 插入位置，越大越靠后；10300 = 最下面
    complete: false     # true = 用这段取代整份系统提示词（会吃掉工具说明，慎用）
    interpolate: false  # 是否对正文做 {{变量}} 插值
    trim: true          # 去掉首尾空白
    tool: true          # 是否注册 prompt_inject 工具
```

## 卸载

**设置 → 插件** 里卸载本插件，然后重启。

## 环境

DeepSeek Harness `0.2.1-rc.2`（cordis 4），无额外依赖。
